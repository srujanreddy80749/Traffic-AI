ℹ️ About This Project

🎯 Project Objective

This is a college project that investigates whether considering predicted future congestion and the impact of rerouting vehicles can reduce overall traffic delay compared to simply picking the fastest current route.

The idea is not completely new — real-world systems like Waze and Google Maps already use some form of rerouting awareness. This project implements an experimental, simplified version and evaluates it against a baseline.

🚧 Known Limitations
  • ⚠ No real-time data: The system does not connect to any live traffic API. All congestion values are simulated.
  • ⚠ Synthetic training data: The ML model is trained on generated data, not actual road measurements. It should not be used for real predictions.
  • ⚠ Small network: The road graph has only 8 nodes — results on a city-scale network would differ.
  • ⚠ Macroscopic simulation: Individual vehicle behaviour, traffic signals, and turning movements are not modelled.
  • ⚠ Simplified rerouting impact: The rerouting model assumes all diverted vehicles take the exact alternative route, which overestimates impact.
  • ✓ SUMO not used: SUMO requires complex configuration and network files. A documented Python simulation is used instead.
